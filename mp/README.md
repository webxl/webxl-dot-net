# Snake 3D multiplayer coordinator

A tiny Cloudflare Worker + Durable Object that pairs two players and relays
WebRTC signalling (and, if the direct link fails, the game traffic itself).

## Protocol

| Endpoint | Purpose |
| --- | --- |
| `POST /create` | Returns `{ "code": "ABCDE" }` — a 5-character challenge code |
| `GET /ws?code=ABCDE&role=host` | Host WebSocket |
| `GET /ws?code=ABCDE&role=guest` | Guest WebSocket |
| `GET /health` | `{ "ok": true }` |

Each room is a Durable Object named after the code, holding at most one host
and one guest socket. Messages are relayed verbatim to the other socket.
`welcome` and `peer-joined`/`peer-left` are generated by the room.

## Local development

```sh
cd mp
npx wrangler dev --port 8787
```

The game connects to `ws://localhost:8787` automatically when served from
localhost. Start the site with `yarn dev` and open
<http://localhost:5173/3dsnake/index.html> in two tabs.

> This environment's automated browser gathers no ICE candidates, so local
> testing uses the relay fallback (the game shows "Connected (relayed)").
> A normal desktop browser will negotiate a direct DataChannel.

## Deploy

```sh
cd mp
npx wrangler deploy
```

Then point the game at the deployed worker. Either edit `MP_COORD` in
`public/3dsnake/index.html`:

```js
return "wss://snake3d-mp.<your-subdomain>.workers.dev";
```

…or pass it at runtime: `?coordinator=wss://snake3d-mp.<sub>.workers.dev`.

The page must be served over HTTPS for `wss://` to work.

## Notes

- Codes are 5 chars from an unambiguous alphabet (~33M combinations).
- Rooms are ephemeral; sockets close when a player leaves. There is no auth —
  fine for casual challenges.
- The relay path adds the Durable Object round-trip to every message; the game
  badges the session as "relayed" so players know.
